
## Latest Javascript Feature 

#### ➡️ Optional Chaining (`?.`):
The optional chaining operator allows safe access to deeply nested object properties without explicitly checking for `null` or `undefined`.

```jsx
const user = {
  profile: {
    name: "Alice",
  },
};

console.log(user.profile?.name); // Alice
console.log(user.address?.city); // undefined (no error)
```

<br>

#### ➡️ Nullish Coalescing (`??`):
The nullish coalescing operator returns the right-hand operand only if the left-hand operand is `null` or `undefined`, ignoring falsy values like `0` or `""`.

```jsx
const value = null ?? "Default Value";
console.log(value); // "Default Value"

const count = 0 ?? 10;
console.log(count); // 0 (not nullish)
```

<br>

#### ➡️ Numeric Separator (`_`):
The numeric separator improves readability of large numbers by using underscores as visual delimiters.

```jsx
const billion = 1_000_000_000;
console.log(billion); // 1000000000
```

<br>

#### ➡️ `Array.prototype.at()`:
The `.at()` method allows accessing array elements using a relative index, including negative values for reverse indexing.

```jsx
const numbers = [10, 20, 30, 40];

console.log(numbers.at(1)); // 20
console.log(numbers.at(-1)); // 40 (last element)
```

<br>

#### ➡️ `String.prototype.replaceAll()`:
The `replaceAll()` method replaces all occurrences of a substring or pattern in a string.

```jsx
const text = "Hello World! World is beautiful.";
const result = text.replaceAll("World", "Universe");

console.log(result); // "Hello Universe! Universe is beautiful."
```

<br>

#### ➡️ Logical Assignment Operators
Logical assignment operators combine logical operations (&&, ||, ??) with assignment.

```jsx
let a = null;
a ||= "Default Value"; // Assign if falsy
console.log(a); // "Default Value"

let b = 10;
b &&= 5; // Assign if truthy
console.log(b); // 5

let c = null;
c ??= "Fallback Value"; // Assign if nullish
console.log(c); // "Fallback Value"
```

<br>

#### ➡️ `Promise.any()`
The `Promise.any()` method returns the first fulfilled promise from a list, ignoring rejections.

```jsx
const promises = [
  Promise.reject("Error 1"),
  Promise.resolve("Success"),
  Promise.reject("Error 2"),
];

Promise.any(promises).then((result) => console.log(result)); // "Success"
```
