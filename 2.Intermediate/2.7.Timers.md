## Timers in JavaScript

#### ➡️ `setTimeout`
The `setTimeout` function executes a callback function after a specified delay (in milliseconds).

```jsx
const greet = () => console.log("Hello, World!");
setTimeout(greet, 2000); // Logs "Hello, World!" after 2 seconds
```

<br>

#### ➡️ `setInterval`
The `setInterval` function repeatedly executes a callback function at a specified interval.

```jsx
const logTime = () => console.log(new Date().toLocaleTimeString());
const intervalId = setInterval(logTime, 1000); // Logs the current time every second
```

<br>

#### ➡️ `clearTimeout`
The `clearTimeout` function cancels a timeout set by setTimeout.

```jsx
const timeoutId = setTimeout(() => console.log("This won't run"), 3000);
clearTimeout(timeoutId); // Cancels the timeout
```

<br>

#### ➡️ `clearInterval`
The `clearInterval` function cancels an interval set by setInterval.

```jsx
const intervalId = setInterval(() => console.log("Running..."), 1000);
setTimeout(() => clearInterval(intervalId), 5000); // Stops the interval after 5 seconds
```

#### ➡️ Debouncing
Debouncing is a technique to limit the rate at which a function is executed by ensuring it runs only after a certain delay has elapsed since the last invocation.

```jsx
const debounce = (func, delay) => {
  let timeoutId;
  return (...args) => {
    clearTimeout(timeoutId);
    timeoutId = setTimeout(() => func(...args), delay);
  };
};

const onResize = debounce(() => console.log("Resized!"), 300);
window.addEventListener("resize", onResize);
```

<br>

#### ➡️ Throttling
Throttling ensures a function is executed at most once in a specified time frame, regardless of how often it is triggered.

```jsx
const throttle = (func, limit) => {
  let lastCall = 0;
  return (...args) => {
    const now = Date.now();
    if (now - lastCall >= limit) {
      lastCall = now;
      func(...args);
    }
  };
};

const onScroll = throttle(() => console.log("Scrolling..."), 500);
window.addEventListener("scroll", onScroll);
```

<br>

### Comparison: Debouncing vs. Throttling

| **Feature**    | **Debouncing**                         | **Throttling**                        |
|-----------------|----------------------------------------|---------------------------------------|
| **Execution**   | Executes after the last event.         | Executes at regular intervals.        |
| **Use Case**    | Input fields, resize events.           | Scrolling, mouse movements.           |
| **Goal**        | Wait until the user stops triggering.  | Limit the rate of execution.          |
